# 🎒 Kruta Shop (ครูต๊ะช็อป) ✏️✨
> **ร้านขายอุปกรณ์เครื่องเขียนการเรียนสุดคิ้วท์ เด้ง ดึ๋ง ปังสุดในสามโลก!**
> พัฒนาด้วย PHP + MySQL (XAMPP) + Bootstrap 5 + CSS3 Bounce Animation + JavaScript Confetti

---

## 🌟 จุดเด่นและลูกเล่นสุดปัง (Features)
1. **ลูกเล่นเคลื่อนไหวดุ๊กดิ๊ก เด้งได้ กระโดดไปมา (Bounce, Tilt & Float Effects):**
   - แบ็คกราวด์ฟองสบู่พาสเทลลอยไปมาอย่างนุ่มนวล (`Bubble Animation`)
   - ไอคอนเครื่องเขียนน่ารัก ๆ กระโดดดึ๋ง ๆ ตลอดเวลา (`jump-infinite`)
   - การ์ดสินค้าและปุ่มเมื่อชี้เมาส์จะเด้งลอยขยายขนาด (`bounce-hover`, `wiggle-hover`)
   - เอฟเฟกต์กระดาษโปรยสีสันสดใส (`Confetti Celebration`) เมื่อกดเพิ่มสินค้าลงตะกร้าและเมื่อสั่งซื้อสำเร็จ!
2. **ระบบสมาชิก & ผู้ดูแลระบบ (Authentication & Role):**
   - สมัครสมาชิกใหม่ / เข้าสู่ระบบด้วยรหัสผ่านแฮชความปลอดภัยสูง (`password_hash`)
   - **รองรับการเข้าสู่ระบบด้วย Google (Google Sign-In ready)** ทั้งแบบคลิกเดียวจบและพร้อมผูก GCP Client ID
   - แยกสิทธิ์ชัดเจนระหว่าง **ลูกค้า (Customer)** และ **ผู้ดูแลระบบ (Admin)**
3. **ระบบหน้าร้าน (Frontend):**
   - ค้นหาเครื่องเขียน (ปากกา, สมุด, สี, ไม้บรรทัด ฯลฯ)
   - กรองสินค้าตามหมวดหมู่สุดน่ารัก
   - ระบบตะกร้าสินค้าแบบโต้ตอบทันใจ (Interactive AJAX Cart) ปรับเพิ่ม/ลด/ลบ พร้อมปุ่มตะกร้าลอยมุมขวาล่าง
   - ระบบติดตามสถานะคำสั่งซื้อ & พัสดุ
4. **ระบบชำระเงินสแกนจ่าย QR Code (PromptPay):**
   - แสดง QR Code พร้อมเพย์ตามยอดรวมเงินจริงอัตโนมัติ สแกนจ่ายได้ด้วยทุกแอปธนาคาร
   - มีช่องอัปโหลดสลิปหลักฐานการโอนเงินเพื่อตรวจสอบความถูกต้อง
5. **ระบบหลังร้านครบครัน (Admin Dashboard):**
   - สรุปยอดขายรวม, จำนวนออเดอร์, สินค้ารอตรวจสอบ, สินค้าในสต็อก
   - จัดการคำสั่งซื้อ ปรับสถานะ (Pending ⏳ -> Paid 💰 -> Shipped 🚚 -> Cancelled ❌)
   - ดูสลิปโอนเงินของลูกค้าได้โดยตรง
   - เพิ่ม ลบ แก้ไข สินค้าเครื่องเขียน และ หมวดหมู่ พร้อมรองรับอัปโหลดรูปภาพ

## 🚀 วิธีเปิดใช้งานกับ XAMPP (ง่ายมากใน 1 นาที)
1. เปิดโปรแกรม **XAMPP Control Panel**
2. กด **Start** ที่โมดูล **Apache** และ **MySQL**
3. เปิดเว็บเบราว์เซอร์ไปที่:
   👉 **http://localhost/kruta2/install.php**
   *(ระบบจะทำการติดตั้งตารางฐานข้อมูล `kruta_shop` และใส่สินค้าเครื่องเขียนตัวอย่างให้อัตโนมัติทันที)*
4. เข้าใช้งานหน้าร้านได้ที่:
   👉 **http://localhost/kruta2/**
